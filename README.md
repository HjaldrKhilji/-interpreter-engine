since https://github.com/HjaldrKhilji/The-Turing-virtual-machine failed, this repo will make use of reflections to finish what I started. The basic concept is that a user can provide a whole interpreted language using this engine. How? he can make the basic programing constructs into types, that are based to the heterogeneous lists, those types will accept a argument, for example for a type named "if", that type will accept a argument of type string, read the string, break it into parts, send each part to the engine to interpreter engine and run, and mark what it read as read. The base way to index is using numbers, but the user will be able to pass flatmap mapping(for example if named as "if"/"if(", names to indexes. It also provides runtime variable dynamic support as well but programming constructs should always stay in the list itself. There is a focus on cache locality and making sure everything is as flat as it can be.
